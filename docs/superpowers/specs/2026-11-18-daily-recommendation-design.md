# 每日英文文章推薦

使用者已選擇讓收藏網站與近期時事一起評選，並明確要求開始實作。

- App 開啟且 ChatGPT 訂閱已授權時在背景搜尋；不阻塞文章庫、閱讀與筆記。
- 當地日期每天固定一篇，SQLite 以日期唯一保存。當天成功後不因重開、換帳戶、模型或來源而替換；失敗可重試。午夜後再次啟用視窗會檢查新日期。
- 優先實作訂閱路徑的原生 web_search。RSS 只作未來替代方案，本次不默默改用無搜尋的模型記憶。帳戶或模型不支援時明確說明。
- 自訂來源為最多 10 個公開網站，僅把正規化網域送給搜尋。與一般近期英文新聞平等參選，不限定在收藏網站中。
- 推薦保留原文標題、公開網址、刊登日期（無法確認則顯示未確認）、繁中推薦理由與可點擊搜尋證據。原文程度以一般美國成年人為準，不簡化、不擷取全文、不繞過付費牆。
- 僅接受實際完成搜尋且推薦網址與回傳搜尋來源一致的結果；無來源、未完成串流或格式不符不保存。
- 不傳文章庫、筆記、私人對話或登入資訊給搜尋提示。Token 留在主程序。
- 保留現有版本號 1.1.1。備份相容舊版並納入來源與推薦，合併時同日期以本機為準；取代時也保留當日本機已固定的文章，避免當天換篇。

## 方法比較
AI 直接搜尋最符合使用者需求；RSS 需要網站提供可用 feed，作為未來備案。選擇前者，對搜尋權限限制明確報錯，不另要求 API Key。
